# Knowledge Tutor

[English](./README.md) | 简体中文

## 核心理念：不要让 AI 使你变笨

用 AI 工具，一个真实的担忧是：**AI 主导了思考，人沦为附属品。** 你问，它想。你复制粘贴，它创造。久而久之，你不再深度思考，变得依赖——人不再是主导者。

但是，更好地使用 AI，反而可以让你进步更快。**关键在于「反思 + 回顾」。** 遇到一个不懂的问题，和 AI 交流过程中搞明白了——很好。但如果没有沉淀下来，下次遇到同样的问题你还是不懂。如果你沉淀下来并经过自己的反思消化，你就变得更强了。

这正是这个 Skill 做的事：它自动从你和 AI 的对话中提取知识，并在之后主动测验你，确保你真正学会了。**AI 始终是强大的工具——你的个性化导师——但你仍然是主导者，而且会越来越强。**

## 项目概述

`knowledge-tutor` 会无缝融入你日常的对话交互中，不仅扮演一个积极的倾听者，更是你主动的导师。它会为你建立一个高度个性化的 Markdown 知识库，专门攻克你欠缺的知识点。你随时可以直接查看、编辑和复习这些针对性极强的 Markdown 文件。

它执行两项核心功能：
1. **被动知识提取：** 智能检测对话中的高价值技术见解，并将其结构化到你的个人 Markdown 知识库中。采用轻量预扫描避免不必要提取，自动检测与已有笔记的重叠，并在长短对话中自适应工作。
2. **主动间隔重复：** 利用定时任务复习你的知识库，并通过苏格拉底式提问（Socratic questioning）主动向你测验，确保你能主动回忆并牢牢掌握复杂的技术概念。

## 核心特性

- **克制提取：** 使用极少量 token 进行预扫描，判断是否值得提取。默认不提取——仅在有真正技术深度时才执行。绝不重复记录知识库中已有内容。
- **自适应扫描：** 扫描范围随对话长度调整。长多轮对话可以产出多次提取，每次覆盖不重复的话题。
- **手动触发：** 更想自己决定,在对话中使用「帮我总结」「提取知识」「记录一下」等关键词随时手动触发提取，直接跳过预扫描。
- **苏格拉底式测验：** 通过引导式的开放性问题来检验你的理解程度，而不是简单的死记硬背。
- **自适应语言：** 技能内部的逻辑推理使用英文驱动，以保证 LLM 执行指令的最佳性能。然而，**它与你的所有对话交互，以及沉淀在知识库中的笔记，都会自动适应你在对话时所使用的语言**。

## 安装指南

### Google Antigravity

```bash
mkdir -p ~/.gemini/antigravity/skills/knowledge-tutor
curl -o ~/.gemini/antigravity/skills/knowledge-tutor/SKILL.md \
  https://raw.githubusercontent.com/niyunsheng/knowledge-tutor/main/SKILL.md
```

*(注意：请确保 Agent 拥有读取和写入目标目录的文件系统权限。默认情况下，笔记会保存在 `knowledge_base` 文件夹中。你完全可以在对话中直接告诉 Agent 更改存储路径！)*

## 使用方法

- **日常对话即可：** 像往常一样与你的 Agent 进行深度的技术探讨。该 Skill 会自适应地发现并保存有价值的知识，避免重复提取。
- **手动触发：** 随时说「帮我总结」「提取知识」「记录一下」等关键词即可手动触发知识提取。
- **每日复习：** 默认情况下，Agent 会在每天 15:00 自动发起一次辅导会话，对你进行知识点测验。*(你可以通过修改 `SKILL.md` 中的 `cron_schedule`，或者直接在对话中让 Agent 帮你修改，来自由更换你喜欢的复习时间。)*
