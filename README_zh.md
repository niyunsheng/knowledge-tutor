# Knowledge Tutor

[English](./README.md) | 简体中文

## 概述

用 AI 工具，一个真实的担忧是：**AI 主导了思考，人沦为附属品。** 你问，它想。你复制粘贴，它创造。久而久之，你不再深度思考，变得依赖。

但更好地使用 AI，反而可以让你进步更快。**关键在于「反思 + 回顾」。** 遇到不懂的问题，和 AI 交流搞明白了——很好。但如果没有沉淀下来，下次遇到同样的问题你还是不懂。如果你沉淀下来并经过自己的反思消化，你就变得更强了。

`knowledge-tutor` 正是做这件事：它从你和 AI 的对话中提取知识，沉淀到个人 Markdown 知识库，专攻你的薄弱环节。自己安排时间复习——学习节奏由你掌控。**AI 始终是强大的工具，但你仍然是主导者。**

## 核心特性

- **克制提取：** 轻量预扫描判断是否值得提取。默认不提取——仅在有真正技术深度时才执行。绝不重复记录已有内容。
- **自适应扫描：** 扫描范围随对话长度调整。长多轮对话可以产出多次提取，每次覆盖不重复的话题。
- **手动触发：** 说「帮我总结」「提取知识」「记录一下」「save this」「extract knowledge」即可随时触发提取。
- **自适应语言：** 所有用户交互和知识库内容自动适配你在对话中使用的语言。

## 安装

```bash
mkdir -p ~/.gemini/antigravity/skills/knowledge-tutor
curl -o ~/.gemini/antigravity/skills/knowledge-tutor/SKILL.md \
  https://raw.githubusercontent.com/niyunsheng/knowledge-tutor/main/SKILL.md
```

*(笔记默认存储在 `~/knowledge_base/`。想改路径，直接告诉 Agent 即可。)*

## 使用方法

- **日常对话即可：** 进行深度技术探讨，该 Skill 会自适应地发现并保存有价值的知识，避免重复。
- **手动触发：** 说「帮我总结」「提取知识」等关键词即可随时触发提取。
- **自主复习：** 随时打开 `~/knowledge_base/` 浏览笔记。自己设一个 cron 或日历提醒，按你的节奏复习。

## 通用 Prompt 模板

不想安装？把下面这段粘贴到任意聊天机器人中，替换方括号部分。

```
请根据我们的对话生成知识库笔记。
我的背景：[你的角色和关注领域，如：AI Infra 工程师，关注训练/推理系统、GPU 集群、MLOps]。
输出：Markdown，语言跟随对话。
```
